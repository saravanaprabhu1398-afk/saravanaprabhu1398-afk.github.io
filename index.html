    Scadea · Global bank (Citi)

    Self-service ingestion where new sources need no code

    Problem
    Ingestion at a global bank depended on manual scheduling and engineering work for each new source.
    What I built
    A PySpark and Apache Camel platform that detects files in landing zones and loads them in parallel into Iceberg tables via control files, with retries and Kafka completion events. Business users define aggregations in SQL and the platform generates the Spark jobs.
