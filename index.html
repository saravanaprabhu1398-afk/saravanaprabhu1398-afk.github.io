    Wipro · Insurance risk

    One risk engine instead of six pipelines

    Problem
    Six fragmented insurance risk pipelines each evaluated claims their own way.
    What I built
    A single Databricks-native risk evaluation engine, structured as rules, validation and scoring classes using Strategy and Factory patterns.
    +40%Claim validation accuracy
    $2M+Est. annual savings in wrongful payouts

    Wipro · Satellite connectivity

    Sub-60-second CDC for 500K+ subscribers

    Problem
    Connectivity events for a satellite internet service needed to reach real-time alerting.
    What I built
    A Debezium and Kafka change-data-capture pipeline into Delta Lake, with min-heap LSN ordering and hash-map deduplication in the merge logic. Separately, cut a recurring 4-hour Spark report SLA breach by 65% for three analytics teams.
    <60sEnd-to-end latency
    500K+Subscribers alerted in real time
    DebeziumKafkaDelta LakeStructured Streaming
    Scadea · Global bank (Citi)

    Self-service ingestion where new sources need no code

    Problem
    Ingestion at a global bank depended on manual scheduling and engineering work for each new source.
    What I built
    A PySpark and Apache Camel platform that detects files in landing zones and loads them in parallel into Iceberg tables via control files, with retries and Kafka completion events. Business users define aggregations in SQL and the platform generates the Spark jobs.
    0Code changes to onboard a source
